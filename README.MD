# chaotic ant 🐜

i came across a reel where an ant was placed at the center of an infinite black grid, following just two rules:

1. if the current square is black: turn it white, turn right, move one square
2. if the current square is white: turn it black, turn left, move one square

that's it. two rules. nothing else.

for the first few thousand iterations, its movement looks completely random and chaotic. it goes in all sorts of directions, leaving behind what looks like a mess.

but then, after roughly 10,000 iterations, something weird happens.

it starts building a straight, repeating road-like pattern. almost as if it suddenly figured out what it was doing.

i didn't believe it, so obviously i had to try it myself.

and yeah, it actually works.

we tend to expect patterns to emerge early if a system is going to have any structure at all. but this thing spends thousands of steps looking chaotic before suddenly settling into a predictable pattern.

anyway, i made this to mess around with it and see what happens.
